# Ketuv BeIvrit Traductor

Aplicación avanzada para la traducción y estudio del hebreo bíblico con análisis morfosintáctico e integración de IA.

## Configuración
Asegúrate de añadir el secreto `GEMINI_API_KEY` en la pestaña de Settings de tu Space.
